# Survival Analysis for Duchenne Muscular Dystrophy: Predicting Loss of Ambulation

## Project Overview

This project compares different machine learning methods for survival analysis to predict loss of ambulation in patients with Duchenne muscular dystrophy (DMD). We explore various ML techniques to analyze and predict the time until a DMD patient loses the ability to walk independently.

## Repository Structure

``

├── README.md

├── requirements.txt

``


## Notebooks

1. `01-data-overview-preprocessing.ipynb`: Initial data exploration and preprocessing steps.
2. `02-final-dataset-eda.ipynb`: Exploratory Data Analysis (EDA) on the final preprocessed dataset.
3. `03-models.ipynb`: Implementation and comparison of different ML models for survival analysis.
4. `04-shap-values.ipynb`: SHAP (SHapley Additive exPlanations) value analysis for model interpretability.

## Utility Functions

`utils.py`: Contains helper functions and utilities used across the notebooks.

## Results

The `results/` directory contains the output and visualizations from our experiments.
